# 监测卡片设计参考

用户喜欢整机功率参考图的功率流向、数值层次与紧凑指标。将这些原则用于 PluginHub 的监测卡片，具体布局、图形和配色按项目主题与数据设计。

- 在单页内先放标题和刷新操作，再突出主图。将异常提示和辅助指标放在图下方，方便先看状态，再读细节。
- 整机功率图以 Mac 为中心。把充电器等外部来源、电池和负载组织成明确节点，用带状连线标示流向。电池根据充放电状态改变方向，外接设备用一个合计节点展示。
- 在线带上叠加缓慢流动的高光。动画根据已知流向播放，与默认每 5 秒的数据采样独立。方向未知时用静态连接，Dashboard 关闭时暂停动画和采样，遵循系统减少动态效果设置。
- 功率数值使用较高对比度及等宽数字，单位紧贴数值。颜色用于区分节点或提示异常，并保留对应的名称与状态文字。用圆角、随主题变化的底色及低对比度分隔延续 PluginHub 样式。
- 供电不足等提示应放在相关数据附近，并依据实测状态触发。充电器规格、温度、风扇及线缆等指标按设备支持情况放到紧凑指标区。
- 实测、估算、暂无数据有明确标注。额定功率和实时输入功率分别标注，未知数值避免使用 0 代替。线带粗细采用功率比例时，仅使用同口径且可比较的数据。
- 原型用实际 Dashboard 宽度检查浅色和深色主题，并覆盖充电、放电、多路电源接入、无外设、数据不可用等状态。优先验证布局和流向是否容易读懂。
